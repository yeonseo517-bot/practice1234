# 영어 낱말장

브라우저에서 바로 여는 영어 단어 학습 페이지입니다. 설치나 빌드는 필요 없습니다.

`index.html`을 더블클릭하면 열립니다.

## 학습 방법

- **카드**: 영어 단어를 보고 뜻을 떠올린 뒤 확인합니다. `알아요`와 `한 번 더`로 표시할 수 있습니다.
- **퀴즈**: 한국어 뜻을 보고 영어 단어 4개 중 하나를 고릅니다. 한 번에 10문제입니다.
- **받아쓰기**: 뜻을 보고 영어 철자를 직접 입력합니다. 철자 하나가 다른 경우는 거의 맞힌 것으로 셉니다.
- **단어장**: 전체 단어를 찾고, 예문을 보고, 아는 단어인지 다시 표시합니다.

왼쪽에서 묶음을 고를 수 있습니다. 전체, 복습, 기본, 일상, 감정, 일, 여행, 사고입니다. 복습에는 `한 번 더`로 표시했거나 퀴즈에서 틀린 단어가 모입니다.

화면 위의 **오늘의 단어**는 날짜마다 하나씩 바뀝니다. **듣기**는 브라우저의 영어 음성으로 발음합니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 카드 뒤집기 |
| `←` `→` | 카드 이동 |
| `1`–`4` | 퀴즈 선택 |
| `Enter` | 받아쓰기 확인 |

## 저장

진도는 이 브라우저의 `localStorage`에만 저장됩니다. 서버로 보내지 않습니다. 다른 브라우저나 시크릿 창에서는 기록이 보이지 않습니다. 사이드바의 **기록 지우기**로 진도를 지울 수 있습니다.

## 구성

단어 61개가 `index.html` 안에 들어 있습니다. 스타일과 동작도 같은 파일에 있습니다.
